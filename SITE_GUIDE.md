# Site Guide

## Home
Use the home page to introduce the research question and provide clear navigation to the rest of the site. Keep the summary short and audience-friendly.

## About
Use this page for biography, affiliation, and motivation. Include personal photos and links to relevant websites, papers, and lab pages.

## Project
This page is the technical one-pager. Include the problem, why it matters, the solution approach, milestones, success metrics, and any constraints on data or experiments.

## Dev Log
Record weekly progress updates here. Each entry should include a date, title, and concise body.

## Content notes
- Keep everything static
- Use public or synthetic data only
- Keep internal links on the Pages helper so the site works in dev and on GitHub Pages
