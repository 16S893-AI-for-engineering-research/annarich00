How the stages are wired

_run_cw_path in src/workflow.py emits a record per plot stage, through an on_artifact callback and a visualization_artifacts list. The order is fixed, and the prompt tells the agent to report each artifact live (the change that displays visualization artifacts live at each pipeline stage).

  1. The 3D scene is emitted before the solve.
  2. The solve calls back _on_solution, which emits the trajectory plot before any GMAT script runs.
  3. After GMAT returns, comparison_stage builds the comparison plot from d_trajectory.txt.

The two-body fallback path emits explicit not_generated records instead of approximate plots.

The CW path emits scene, then the solve callback, then the comparison.
