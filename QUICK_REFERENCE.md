# Quick Reference

- Home page: `src/pages/index.astro`
- About page: `src/pages/about.astro`
- Project page: `src/pages/project.astro`
- Dev log: `src/pages/dev-log.astro`
- Base layout: `src/layouts/BaseLayout.astro`
- Shared path helper: `src/lib/paths.ts`
- Theme and global styles: `src/styles/globals.css`

## Add a new dev log entry
Edit the `entries` array in `src/pages/dev-log.astro`.

## Add photos
1. Put image files in `public/images/`
2. Reference them from the page using the GitHub Pages base path
3. Always include descriptive alt text
